# deRogue

Static site for deRogue partner-connection workshops. GitHub Pages publishes this repository from the default branch, root (`/`).

The custom domain in `CNAME` is `derogue.art`.

Expected live URLs after GoDaddy DNS propagates and Pages issues TLS:

- https://derogue.art
- https://www.derogue.art

DNS records are in [DNS.md](DNS.md).

The same site is also published at https://roguebachata.com/derogue/ from [test-rogue-plan](https://github.com/goodfornothin/test-rogue-plan). That repository keeps its own `CNAME` of `roguebachata.com`.
